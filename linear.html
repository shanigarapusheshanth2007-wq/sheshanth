Linear Regression

Predicting target values using a straight line fit.

Key Concepts

📏

Best Fit Line

Minimizes distance between predicted values and actual data.

📉

Cost Function

Calculates error using Mean Squared Error (MSE).

⚡

Gradient Descent

Optimization algorithm to update parameters automatically.

Python Code Example

import numpy as np from sklearn.linear_model import LinearRegression # Prepare sample training data X = np.array([[1], [2], [3], [4], [5]]) y = np.array([2, 3.5, 5, 6.5, 8]) # Initialize and train model model = LinearRegression() model.fit(X, y) # Make a prediction prediction = model.predict([[6]]) print(f"Prediction for X=6: {prediction[0]}")
